## Projetos

- [sistema-gerenciamento-estoque-python](https://github.com/geovannacavalcante0806/sistema-gerenciamento-estoque-python): sistema de terminal para controle de estoque, com cadastro de produtos, entradas e saídas, histórico, alertas de estoque mínimo e relatório gerencial. Python e SQLite.
- [Projeto-Estruturas-de-Repeticao](https://github.com/geovannacavalcante0806/Projeto-Estruturas-de-Repeticao): simula o monitoramento de temperatura de uma máquina industrial. Valida as entradas, calcula média, maior, menor e percentual de leituras acima do limite, e encerra sozinho após 3 leituras consecutivas acima do limite. Feito em C.
- [Algoritmos-e-Pensamento-Computacional](https://github.com/geovannacavalcante0806/Algoritmos-e-Pensamento-Computacional): menu com 20 expressões matemáticas (soma, média ponderada, área do triângulo, conversão de temperatura, desconto e acréscimo percentual, entre outras), feito em fluxograma no Flowgorithm.

## Como escolhi organizar este perfil

Ao analisar os perfis profissionais no GitHub, percebi que os desenvolvedores valorizam bastante a organização e a apresentação dos seus trabalhos. Um padrão que chamou minha atenção foi a utilização de READMEs para explicar quem são, quais tecnologias utilizam e quais projetos desenvolveram. Também observei que os repositórios fixados geralmente apresentam os trabalhos mais relevantes de cada profissional. Outro ponto importante foi a documentação clara, com explicações sobre as funcionalidades e instruções para executar os projetos. Percebi também o uso de badges e ícones para apresentar as tecnologias de maneira visual, sem deixar o perfil muito carregado. A presença de arquivos como LICENSE e .gitignore demonstra preocupação com a organização e as boas práticas de desenvolvimento. Além disso, a atividade frequente e as contribuições em projetos de código aberto mostram o envolvimento dos profissionais com a comunidade. Com essa análise, pretendo organizar melhor meu próprio perfil, utilizar uma apresentação mais profissional, destacar meus projetos acadêmicos e documentar meus códigos com mais cuidado. Como estudante de Ciência da Computação, vejo o GitHub como uma oportunidade de registrar minha evolução e construir meu portfólio desde o início da graduação.
